나비야 정원 v1.0 — 센서 악기 합주 리듬 확인 화면
====================================================

관악기·하프·드럼이 박자에 맞게 들어왔는지 보여 주는 화면입니다.
판정은 STM32가 하고, 화면은 표시만 합니다. 키보드 모드에서만 화면이 판정을 흉내 냅니다.
PC는 소리를 내지 않습니다.

1. 실행
-------
  이 폴더에서:   python -m http.server 8000
  크롬/엣지에서: http://localhost:8000

  index.html을 더블클릭해도 키보드 모드는 됩니다.
  시리얼(Web Serial)은 http://localhost 로 열어야 합니다.

2. 키
-----
  시작 화면   ← →  템포(70/80/90/100/110)    Space  시작(카운트 4박)
  연주        A 관악기 / S 하프 / D 드럼      A를 누르고 있으면 관악기 유지 표시
              Shift+키  음 틀림 흉내           Esc  중단하고 시작 화면
  어디서나    T 자동 연주(전부 Perfect, 채보 확인)   R 무작위 데모(판정 연출 확인)
              L 로그 재생 창 여닫기
  결과 화면   Space 다시    "기록 CSV 복사" 버튼

3. 시리얼 형식 (115200bps, 한 줄에 하나, 쉼표 구분, 줄 끝 \n)
---------------------------------------------------------------
  BEAT,<박번호>                      Uno 박자(0부터). 화면 시계를 맞춘다
  MODE,DMA_ON | MODE,DMA_OFF         이번 판 이름
  <악기>,<이벤트>,<음>,<세기>,<박번호>,<오차ms>[,<등급>]
     악기    W(관악기) H(하프) D(드럼)
     이벤트  ON(시작) OFF(끝, 관악기 유지 표시용)
     음      DO RE MI FA SOL / 드럼은 KICK SNARE
     세기    0~100 (하프는 0)
     오차ms  박 대비, +면 늦음
     등급    P G B M (선택). 없으면 화면이 CONFIG의 판정 창으로 등급만 붙인다
  예)  W,ON,MI,72,21,+12    H,ON,RE,0,22,-8,G    D,ON,KICK,88,22,-3    W,OFF,MI,0,22,+640

  - 모르는 줄은 무시하고 화면 아래와 로그 창(L)에만 남긴다.
  - 포트는 1~4개. Uno가 모아 한 줄로 보내든, 허브로 보드마다 보내든 같은 파서로 합친다.
  - 같은 BEAT가 여러 포트에서 오면 한 번만 쓴다.
  - 이벤트가 안 온 노트는 판정 창 + 0.3초 뒤 화면이 Miss로 표시한다(보드는 Miss를 보내지 않는다).
  - 시리얼 모드에서 Space를 누르면 Uno의 첫 BEAT를 기다렸다가 그 박에 맞춰 시작한다.
    Space를 한 번 더 누르면 화면 시계로 바로 시작한다.
  - 다른 프로그램(CubeIDE 터미널 등)이 COM 포트를 잡고 있으면 닫는다.

4. 로그 재생 (L)
----------------
  터미널로 받아 둔 시리얼 줄을 붙여넣고 "재생"을 누르면, 보드 없이 그 판을 다시 볼 수 있다.
  결과 화면에서 복사한 기록 CSV도 그대로 붙여넣으면 재생된다.

5. 그림 넣기
------------
  그림 파일을 assets/ 폴더에 넣고, assets/manifest.js 의 목록에 파일 이름을 적는다.
  목록에 없는 그림은 코드로 그린 대역으로 나온다(그림이 하나도 없어도 전부 동작).
    bg_play.png  title_key.png  title_loop.mp4  result_garden.png
    butterfly_do/re/mi/fa/sol/grey.png   (한 장만 있어도 됨. 없는 색은 색조를 돌려 만든다)
    flower_bud/half/full/wilted.png      (flower_full 한 장만 있어도 됨. 흰 꽃에 행별 색을 입힌다)
    dewdrop.png  seed_kick.png  seed_snare.png

6. 숫자 고치기
--------------
  index.html 맨 위 CONFIG 한 곳에 모여 있다: 판정 창(ms), 점수, 등급 기준, 템포 목록·기본값,
  1박 px, 합주 기준, 최대 포트 수, 행 색, 시리얼 Miss 여유.
