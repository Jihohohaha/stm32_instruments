# Uno 지휘자

| 폴더 | 내용 | 상태 |
| --- | --- | --- |
| `conductor/` | 지휘자 v0: `START` → 카운트 4박 → `BEAT,0~63` + D8 펄스 → `END` | PC 시뮬레이션으로 박 간격·펄스 폭·곡 사이 쉬는 시간 확인. **실제 Uno 미검증** |
| `uno_beat_test/` | 관악기 v2 시험용 (리셋 3초 뒤 90 BPM 64박) | 관악기 v2와 함께 올릴 예정 |

Arduino IDE는 폴더 이름과 `.ino` 이름이 같아야 연다. `conductor/conductor.ino`를 그대로 열면 된다.

아직 안 하는 것: I²C로 세 보드 기록 모으기, Uno에서 채점·점수 표시. 연결 구조(허브 / Uno가 모아서)가 정해지면 추가한다. 지금 판은 허브 구조에서 그대로 쓸 수 있다.

시험 방법 (게임 없이)

1. 굽고 시리얼 모니터 115200, 줄 끝 "Newline".
2. `START,90` 입력 → `COUNT,4`~`COUNT,1` 뒤 `BEAT,0`~`BEAT,63`, `END`.
3. D8을 STM32 박자 입력(분압 거쳐)에 연결하면 관악기 이벤트 줄의 박번호가 0부터 맞게 나오는지 본다.
